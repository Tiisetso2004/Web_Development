# Web Development

This repository serves as the central hub for tracking, developing, and validating web development projects throughout the module.

## Purpose of This Repository

* **Module Progression:** Document comprehensive web development growth and milestones throughout the course.
* **Academic Reference:** Serve as the primary, production-ready reference codebase for POEs, assignments, and open-book exams.
* **Skill Verification:** Act as credible, auditable evidence of authentic skill proficiency, advanced coding capabilities, and complete code ownership.
* **Academic Integrity:** Maintain clear separation between independent work, external tutorials, and AI-assisted conceptual learning.

---

## Reference Dockets

To ensure transparency and academic legitimacy, all external influences and learning aids are strictly tracked in the specialized dockets below:

* [Standard Reference Docket (REFERENCES.md)](./REFERENCES.md) — View tracked code snippets, video tutorials, and official documentation used during development.
* [AI Reference Docket (AI_REFERENCES.md)](./AI_REFERENCES.md) — View transparent logs detailing AI usage for troubleshooting, debugging, and conceptual explanations.
